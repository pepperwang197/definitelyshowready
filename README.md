### a really cool music rehearsal software!

### [demo :)](https://pepperwang197.github.io/definitelyshowready/)

<br/>
includes:

- ability to change volume, mute, or solo individual tracks
- select multiple tracks to change all their settings at the same time
- click track included for each song
- metronome
- on screen piano which supports input from MIDI devices
